# WorkPulse Web

Активный интерфейс ЛР9 подключён к REST API и PostgreSQL. React/TypeScript, Motion, Radix Dialog, Tabler Icons, локальные шрифты Manrope. Сохранены светлая мятная тема, горизонтальная навигация, минималистичная иллюстрация и адаптивная компоновка.

Вход по паролю, обзор, сотрудники и сессии, нарушения с рассмотрением, версии политик, история анализа/CSV, пользователи/подразделения/устройства. Изменения сохраняются на сервере; область роли проверяется API. KPI не подменяются вымышленными процентами. Предыдущий frontend-only прототип сохранён в `src/App.tsx`; активный компонент – `src/LiveWorkspace.tsx`.

## Запуск

Сначала выполните [общий гайд](../server/api-guide.md), затем из этой папки:

```shell
npm ci
npm run dev -- --host 127.0.0.1 --port 4173
```

Vite проксирует `/api` на `127.0.0.1:5080`. Самостоятельная статическая публикация не создаёт backend. Cookie используется через один origin; токены устройств не хранятся в localStorage. Локальный файл пароля находится вне UI, в игнорируемом `tmp`.

Проверки: `npm run check`, `npm run build`, `npm run test:sites`. Chrome desktop/mobile: вход, шесть разделов, результат анализа, CSV и отсутствие администраторских кнопок у HR. Подробности: [lr9-verification.md](../server/lr9-verification.md).

[Исходный редактируемый макет Figma](https://www.figma.com/design/ANBCWFTYaghJqVXF43wvEr?node-id=6-27) отражает прототип ЛР6; серверные формы и состояния ЛР9 реализованы в коде. Макет не обновлялся на этом этапе.

ЛР10: ReportingPanel показывает реальные KPI/сравнение периодов и скачивает PDF/XLSX. Добавлены график политики, ресурсы, фильтры нарушений и подробности для сотрудника. Браузерный тест: npm run test:live (работающие API/БД/UI, Chrome; сначала server/tests/lr10-integration.py).
