# Проверка реализации ЛР8

Дата: 12.10.2026. Среда: Windows x64, локальный .NET SDK 10.0.401, Release/net10.0. Внешние NuGet-пакеты, сеть, PostgreSQL и живой агент в проверках алгоритмов не использовались.

## Результаты

| Проверка | Результат |
|---|---|
| Сборка WorkPulse.slnx | Успешно, 0 ошибок, 0 предупреждений |
| Консольный тестовый проект | 19/19 групп, код завершения 0 |
| Случайные шкалы | 100 наборов × 40 событий, seed 814301; покрытие, отсутствие пересечений и инвариантность к перестановке |
| Демонстрация | 360 секунд: 60 Productive, 120 Idle, 60 Lunch, 120 Productive; одно нарушение Idle при лимите 30 секунд |
| UML | 7 исходников локально построены в SVG/PNG, синтаксических ошибок нет; изображения просмотрены |
| Чертёж | SVG A4 и PNG просмотрены; шаблон основной надписи окончательно не согласован |

## Группы проверок

1. Ограничения сессии/перерывов, один обед, отсутствие перехода при ошибке.
2. Ночная смена без привязки к календарной полуночи.
3. Допустимые/недопустимые сигналы начала сессии.
4. Принадлежность политики tenant и публикация до начала.
5. Отсутствие событий даёт Unknown без нарушения.
6. Общий Idle только при подтверждении всех ожидаемых устройств.
7. Последний ввод выбирает устройство, время не удваивается.
8. Равные времена дают стабильный выбор DeviceId.
9. Дубликат доставки не меняет результат; конфликт payload отклоняется.
10. Обратный порядок получения не меняет шкалу.
11. Истечение актуальности, поздний heartbeat и heartbeat точно на границе.
12. Обед/разрешённое отсутствие перекрывают активность и разрывают нарушение.
13. Ровно лимит допустим, превышение создаёт нарушение; непрерывная категория объединяется.
14. Позднее событие создаёт новый запуск без изменения старого.
15. Проверки tenant, employee, device, периода, параметров и версии политики.
16. Незнакомый ресурс Neutral; справочник политики скопирован и неизменяем.
17. Полуоткрытые границы, ограничение концом сессии, открытый перерыв ограничен периодом анализа.
18. Logout устройства не закрывает общую сессию.
19. Случайные временные шкалы: положительные интервалы, точное покрытие и детерминизм.

Воспроизведение из корня: `./server/run.ps1 -Action build`, `-Action test`, `-Action demo`.

Не проверены промышленная производительность, конкурентный приём событий, транзакционный адаптер PostgreSQL, HTTP/RBAC, агент, расписание фоновых задач, UI и доставка уведомлений. Эти части не объявляются реализованными.
