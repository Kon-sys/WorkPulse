# Проверка реализации ЛР9

Дата: 13.10.2026. Проверена локальная связка Windows – UI – REST API – PostgreSQL.

- Сборка решения .NET: 0 ошибок, 0 предупреждений; 19/19 групп тестов ядра.
- HTTP: 29 интеграционных проверок. Проверены cookie/CSRF, роли и tenant-изоляция, токены, дедупликация, сессии, сохранённые результаты, поздние события и история нарушений.
- PostgreSQL: Flyway validate, исходные V001–V007 сохранены; V008/V009 применены. Пройдены 17 ожидаемых отказов целостности и проверки RLS через ограниченного пользователя workpulse_app.
- Агент: self-test дискового буфера; реальный ручной запуск Windows на 6 секунд. События доставлены, сессия и анализ сохранены; буфер пуст. Тестовый токен отозван через вывод устройства из эксплуатации, временная конфигурация удалена.
- UI: TypeScript, production build, 4/4 теста упаковки; браузерная проверка входа, шести разделов, сохранённого анализа, CSV, мобильной ширины и доступности действий HR; ошибок JavaScript нет.
- Проверены визуально desktop/mobile и три UML-диаграммы. Сохранённые результаты доступны после перезапуска API.

Команды и ограничения: [api-guide.md](api-guide.md). Контракты: [api-contract.md](api-contract.md). UML: [design/lr9-models.md](design/lr9-models.md).

Проверки используют синтетические данные двух демоорганизаций. Это не нагрузочное тестирование и не подтверждение всех требований будущих ЛР. KPI, допуски опозданий, браузерное расширение, интеграции и доставка уведомлений не реализованы. Списки ограничены, полноценная пагинация будущая; набор ожидаемых устройств фиксирован для запуска анализа. Исторические seed-сессии ЛР7 могут нарушать проверку времени публикации политики: для демонстрации создавайте новые сессии.

Отчёт DOCX по ЛР9 сформирован и визуально проверен 13.10.2026 (17 страниц). Публикация GitHub и PR выполняются по отдельной команде пользователя.

Повторный прогон перед отчётом: 29 API-проверок, 19 групп ядра, self-test агента, браузерные сценарии UI и Flyway validate прошли. Проверка молчащего устройства учитывает небольшое расхождение часов контейнера и Windows ожиданием после регистрации.
