# Результаты проверки ЛР10

Дата: 14.10.2026. Ветка feature-testing. Документирует проверенную локальную сборку.

- Сборка .NET: без ошибок и предупреждений после остановки блокировавшего DLL тестового API.
- xUnit: 71/71, без пропусков. TRX и Cobertura в tmp/lr10/coverage; [покрытие](coverage-summary.md) включает Domain, Application, API и Infrastructure. Только модульные тесты: 27.67% строк всего; Domain 98.90%, Application 97.48%, API 12.97%, Infrastructure 1.20%. HTTP и браузер не включены в эти проценты.
- Реальный HTTP/PostgreSQL: 52/52 проверки. График, допуски, опоздание/ранний уход, KPI, latest-run без двойного учёта, разные периоды 100% → 0%, ролевые/tenant-ограничения, отрицательные параметры, PDF/XLSX.
- Chrome: формы ресурсов/политик, недельный график, четыре фильтра нарушения, комментарий и повторное чтение, сохранённый анализ, CSV, KPI, сравнение −100 п.п., оба экспорта, мобильная ширина, выход/смена роли и пустой журнал второй организации; ошибок JavaScript нет.
- SQL: V010 применена, Flyway validate успешен; 17 ожидаемых отказов целостности и RLS через workpulse_app проходят. V001–V009 неизменны.
- Агент: self-test буфера и реальный 6-секундный запуск. Сигналы доставлены до сессии/анализа, буфер пуст, тестовый токен отозван; пользовательская конфигурация восстановлена или временная удалена.
- Экспорты: PDF с кириллицей и XLSX с числовыми значениями прочитаны; многостраничный PDF проверен на 100 длинных именах; XLSX сохраняет имена как текст без исполнения формул. Скриншоты desktop/mobile и первая страница PDF просмотрены. UI build/check и 4/4 теста упаковки прошли.

[Матрица 32 FR](requirements-matrix.md), [тест-кейсы](test-cases.md), [запуск и границы](README.md).

Проектные ограничения не скрываются: неизвестные/неоднозначные границы не дают оценки графика; таймлайн строится внутри сессий; сайты доступны для настройки классификации, настоящий агент по согласованию собирает только процесс и состояния ввода. FR2-2 изменён пользователем. Нагрузочные показатели и производственная доступность не измерялись. Минимальное покрытие методичкой не задано; модульное покрытие SQL/HTTP-адаптеров остаётся низким, несмотря на успешный интеграционный прогон.

Отчёт DOCX ЛР10 пока не создавался. Коммит/push/PR в этой задаче не выполнялись. Тестовые API/UI/БД остановлены после проверки с сохранением данных.
