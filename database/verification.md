# Проверка базы WorkPulse — 12.10.2026

Фактически проверено на Docker Desktop / Linux containers: PostgreSQL 18.6, Flyway Community 13.10.0. Образы закреплены digest в Compose.

| Проверка | Результат |
|---|---|
| V001–V007 на пустой `workpulse_freshcheck` | Все 7 применены; итог V007 |
| Инкрементальное применение в `workpulse` | Успешно |
| Повторный `up` / migrate | Новых изменений нет |
| Flyway validate | Checksum и история согласованы (8 записей включая создание схемы) |
| Seed с двумя организациями | Успешно, повторный запуск не добавил дубликаты |
| 13 ожидаемых отказов integrity.sql | Получены требуемые SQLSTATE, а не произвольные ошибки |
| Допустимые операции | Ночная смена, второй ПК, обновление категории интервала |
| Автоматический аудит | Запись изменения опубликованной версии присутствует |
| TCP-вход как workpulse_app | Успешно; роль не superuser и не BYPASSRLS |
| RLS без контекста | Организации скрыты |
| RLS с контекстом | Видна только выбранная организация |
| Чужие UPDATE/INSERT | UPDATE затронул 0 строк, INSERT запрещён |
| DDL и удаление аудита под app | Запрещены |
| Сброс контекста после транзакции | Подтверждён |
| Custom-format pg_dump + копирование на хост | Успешно |
| pg_restore в новую workpulse_restorecheck | Успешно; integrity + SaaS isolation повторно прошли |

Тесты целостности откатывают собственные изменения. В основной БД остались только демонстрационные записи. Вспомогательные `workpulse_freshcheck` и `workpulse_restorecheck` после проверки удалены; рабочая БД и volume сохранены.

После завершения контейнеры проекта WorkPulse остановлены и удалены командой Compose `down`, без `-v`. Volume `workpulse-database_pgdata` сохранён. Посторонние контейнеры не затронуты.

Не проверялись: API-аутентификация/RBAC, агент, реальные интеграции, нагрузка/конкурентный стресс-тест, промышленное восстановление на другом сервере, расчёт KPI и отчётные файлы. Эти функции не реализованы в рамках слоя хранения.
