# WorkPulse Windows Agent

Ручной сборщик метаданных активного процесса и состояния ввода в пользовательской сессии Windows. Служба и автозапуск не устанавливаются. .NET 10, Win32 `GetForegroundWindow`, `GetWindowThreadProcessId`, `GetLastInputInfo`; домены сайтов, заголовки и содержимое окон не собираются.

Подключение устройства и настройки: [полный гайд](../server/api-guide.md#3-подключение-windows-агента).

Из корня:

```powershell
.\agent\run.ps1 -Action build
.\agent\run.ps1 -Action test
.\agent\run.ps1 -Action run
```

Перед `run` создайте `agent/appsettings.Local.json` из примера и вставьте токен, выданный администратором через UI. Этот файл игнорируется Git. Для ограниченной проверки: `-DurationSeconds 6`. Для остановки – Ctrl+C. Токен и буфер нельзя помещать в репозиторий.

`DiskOutbox` публикует событие через временный файл и атомарное переименование, переживает перезапуск, сохраняет очередь при ошибках сети и удаляет только подтверждённые идентификаторы. До 10 000 событий, повторы 5–60 секунд. Отзыв токена останавливает сбор. 400/409 требуют проверки часов/конфигурации/конфликтующего события; очередь не очищается автоматически.

Тест буфера не собирает реальную активность. Реальный Win32-сбор и доставка в локальную PostgreSQL отдельно проверены в ЛР9 в течение шести секунд на отозванной после проверки регистрации.
