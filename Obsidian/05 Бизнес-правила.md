# Бизнес-правила

Источники: [[ЛР1 — извлечённый текст]] §2.2.2, [[ЛР3 — извлечённый текст]] §1.2, [[ЛР4 — извлечённый текст]] UC-1–UC-5 и FR.

| Правило | Что установлено в материалах |
|---|---|
| Начало сессии | Вход в корпоративную среду или начало активности на ПК |
| Окончание сессии | Выход, завершение сессии/активности или время окончания смены |
| Обед | Не более одного раза за смену; начало и конец фиксируются отдельно |
| Допустимый обед | Исключается из расчёта простоев и нарушений |
| Превышение обеда | Возможное нарушение при превышении допустимой длительности |
| Простой | Отсутствие событий ввода/рабочей активности в заданном интервале |
| Порог простоя | Настраивается политикой; может различаться по должности/подразделению |
| Категории | Продуктивная, нецелевая, нейтральная; простой отдельно учитывается в FR4-3 |
| Неизвестное приложение/сайт | Нейтральная категория, затем настройка справочника по UC-4 |
| Отклонения | Простои сверх лимита, длительная нецелевая активность, опоздание, ранний уход, превышение перерыва |
| Разрешённое отсутствие | Не считается нарушением по альтернативе UC-5 |
| Контекстная фиксация | Только при нарушении и после уведомления; постоянные/периодические снимки не применяются |
| Хранение | Ограничено политикой; точный срок не указан |
| Доступ | Разграничивается по ролям |

**Открыто:** приоритет сигналов завершения дня, ручной или автоматический обед, работа после смены, ночные смены, несколько устройств, разрешённые отсутствия, периоды без связи, часы и часовые пояса. Не считать отсутствие данных доказанным простоем без согласованного правила.

ЛР1 использует три категории, а ЛР3/4 добавляют нейтральную. Для карты сохранена более подробная модель ЛР4; это вывод анализа, не незаметное изменение исходника.
