# Роли и доступ

Источники: [[ЛР3 — извлечённый текст]] (процессы и ответственность), [[ЛР4 — извлечённый текст]] (UC), [[ЛР5 — извлечённый текст]] (JWT/RBAC и область доступа).

| Роль | Задачи по материалам | Граница доступа |
|---|---|---|
| Сотрудник | Работа на ПК, рабочая сессия, обед, получение уведомлений | Не получает сводную аналитику подразделения по ЛР5; личный кабинет не специфицирован |
| HR-специалист | Политики, журнал нарушений, отчёты, анализ | Область доступных подразделений ещё не определена |
| Руководитель подразделения | Отчёты и анализ своей команды, журнал нарушений | Только свои сотрудники по ЛР5 |
| Топ-менеджмент | Сводные KPI, сравнение и управленческие решения | Детализация персональных данных не определена |
| ИБ / compliance | Ограничения мониторинга, политики, журнал событий/нарушений | Точная матрица полномочий не определена |
| Системный администратор | Пользователи, роли, технические параметры | Изменение политик есть в таблице FR, но отсутствует среди акторов сценария UC-1 |

IT-руководитель, DevOps и служба поддержки выделены в ЛР3 как участники процессов внедрения и эксплуатации. Это не автоматически отдельные роли авторизации веб-приложения.

Матрица ЛР3 использует знаки «+» для ответственности; это не полноценная RACI-матрица. Ответственность за бизнес-процесс не следует автоматически превращать в разрешение API.

Для будущей реализации нужно согласовать действия «читать / создавать / изменять / экспортировать» и области «свои данные / подразделение / организация». Конкретная матрица ещё не утверждена.
