# Технологический стек

Источник: [[ЛР5 — извлечённый текст]], §2–3, страницы PDF 8–13. Это выбор в лабораторной, а не подтверждение установленных зависимостей.

| Слой | Выбранная технология | Обоснование документа |
|---|---|---|
| Web | React + TypeScript | Компоненты, типизированные данные, таблицы и дашборды |
| Backend | ASP.NET Core / C# | REST API, авторизация, фоновые процессы |
| Агент на ПК | .NET Worker Service | Фоновый сбор и передача событий |
| Хранение | PostgreSQL, возможное использование JSONB | Связанные данные, транзакции, SQL-аналитика |
| Обмен | REST / JSON, HTTPS; SQL/TCP для БД | Разделение клиентов и сервера |
| Доступ | JWT + RBAC | Аутентификация и роли |

Сравнивались React/Angular/Vue, ASP.NET Core/Spring Boot/Node.js + NestJS, PostgreSQL/MySQL/MongoDB. В таблице упоминаются EF Core и Dapper, но окончательный выбор ORM отдельно не утверждён.

Версии .NET, React, PostgreSQL, сборщик, библиотеки графиков/UI, схема миграций, хостинг, установка и обновление агента не определены. .NET Worker Service сам по себе не задаёт способ доступа к пользовательской сессии, окнам и браузеру — это отдельная техническая задача.

**Решение пользователя:** дизайн ЛР6 не переносить как обязательный; к новому дизайну вернуться позже.
