# Данные и термины

Источники: [[ЛР3 — извлечённый текст]] §1.1, [[ЛР4 — извлечённый текст]], [[ЛР5 — извлечённый текст]] §1.4. Это концептуальная модель; готовая ER-схема и миграции не предоставлены.

| Сущность / понятие | Смысл и известные данные |
|---|---|
| Сотрудник / пользователь | Участник организации; роли доступа; кадровые сведения из HRM/ERP |
| Подразделение / должность | Организационная структура и область аналитики |
| WorkSession | Рабочая сессия с началом, концом, активностью и обедом |
| ActivityEvent | Событие активности на ПК; основа классификации и простоев |
| MonitoringPolicy | График, допустимый простой, обед, категории/списки, ограничения хранения и доступа |
| Справочники | Приложения, сайты, категории; редактируются без изменения кода |
| ViolationRecord | Зафиксированное отклонение; детали и комментарии ответственного пользователя |
| KpiMetric | Рассчитанный показатель по сотруднику/подразделению и периоду |
| Аналитический отчёт | Представление показателей, экспорт PDF/XLSX |
| История изменений | Изменения политик, доступа и классификации |

Рабочее время — время трудовых обязанностей по графику; рабочая сессия — интервал рабочего дня с активностью, обедом и простоями. Продуктивная активность соответствует задачам; нецелевая не связана с ними; неизвестная по UC-4 нейтральна. Простой — отсутствие активности, которое может иметь объективную причину. Нарушение — отклонение от политики, а не синоним любого простоя.

Из ЛР5 известно отношение WorkSession → набор ActivityEvent и использование MonitoringPolicy при создании ViolationRecord. Число политик на сессию, версии правил, поля сущностей и внешние ключи ещё не заданы.

## Детали, которые не следует выдумывать

Нет утверждённых контрактов событий, частоты сбора, идентификаторов устройств/сессий, схемы многопользовательского SaaS, часовых поясов, правил пересекающихся интервалов и расчёта длительности. Не определено, хранится ли отчёт отдельной сущностью или строится по запросу; равно как и сохранение агрегатов KPI.
